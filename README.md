# 小学数学趣味练习

一套适合小学生的数学趣味练习网页应用，支持 iOS 和 Android 手机端完美显示。

## 📱 在线体验

直接访问 GitHub Pages 地址即可使用：
- **首页**: https://[你的用户名].github.io/[仓库名]/
- **数数练习**: https://[你的用户名].github.io/[仓库名]/counting.html
- **01大法**: https://[你的用户名].github.io/[仓库名]/index.html

## 🎮 功能介绍

### 🔢 数数与数数字
- **数数练习**: 输入起始数和结束数，计算总数并展示数字序列
- **数数字练习**: 计算指定范围内所有数字的位数总和
- **数页码练习**: 根据数字总数计算页数，理解位数与页数的关系

### 🧦 01大法
- 用可爱的袜子可视化学习奇偶判断
- 输入5个数字，实时显示总和的奇偶性
- 动态袜子配对展示，直观理解奇偶概念

## 🚀 部署到 GitHub Pages

1. **Fork 或上传代码**
   - 将所有文件上传到 GitHub 仓库

2. **开启 GitHub Pages**
   - 进入仓库 → Settings → Pages
   - Source 选择 `main` 分支和 `/(root)`
   - 点击 Save

3. **访问你的网站**
   - 等待 1-2 分钟，网站即可访问
